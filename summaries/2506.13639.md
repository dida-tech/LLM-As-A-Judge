# An Empirical Study of LLM-as-a-Judge: How Design Choices Impact Evaluation Reliability（arXiv:2506.13639）

## 0 基本信息
- **作者**（按署名）：Yusuke Yamauchi（The University of Tokyo；† Equal contribution；标注"Work done during an internship at NEC Corporation"）、Taro Yano（NEC Corporation）、Masafumi Oyamada（NEC Corporation）。共 3 人。
- **发布/更新日期**：论文正文未写明具体日期；arXiv ID 2506.13639 对应 2025 年 6 月提交（论文未明确说明，此日期由 ID 推断）。
- **一句话核心主张**：[LLM-as-a-Judge](../concepts/llm-as-a-judge.md) 的可靠性高度取决于评估设计——同时给出参考回答（reference answer）与[评分描述](../concepts/evaluation-criteria.md)（score descriptions）能显著提升与人类判断的对齐度；用采样[解码](../concepts/decoding-strategies.md)（sampling）+ 分数平均（Mean）聚合优于确定性 [greedy](../concepts/decoding-strategies.md) [解码](../concepts/decoding-strategies.md)；而一旦[评估标准](../concepts/evaluation-criteria.md)清晰，[CoT](../concepts/chain-of-thought.md) 推理带来的收益很小。

## 1 解决什么问题（Problem）
- **动机/背景**：LLM（专有与开源）快速演进，需要可靠的评估手段，尤其是开放式、指令跟随类任务（open-ended evaluation）。人工评估成本高、速度慢，[LLM-as-a-Judge](../concepts/llm-as-a-judge.md)（Zheng et al., 2023）用评估 LLM 给被测 LLM 打分，更低成本、更快（Section 1/Introduction）。
- **研究问题**：两项决定可信度的关键性质——(1) 与人类判断的对齐（Alignment with human judgments）；(2) 评估结果的一致性（Consistency of evaluation results）。缺少这两者，自动评估可能得出误导性结论（Section 1）。
- **三个 RQ**（Section 3）：
  - RQ1：评估设计的哪些组件（[评估标准](../concepts/evaluation-criteria.md)、[参考答案](../concepts/reference-quality.md)）能提升与人类判断的对齐与一致性？
  - RQ2：确定性（deterministic）vs 非确定性（non-deterministic）[解码策略](../concepts/decoding-strategies.md)各自的优缺点？
  - RQ3：[CoT](../concepts/chain-of-thought.md) 能否提升与人类判断的对齐与一致性？
- **定位**：作者声称这是首个系统研究"评估任务设计与评估策略会造成评估结果多大波动"的工作——已有研究多关注偏置（gender/authority/positional/self-enhancement 等），本文聚焦设计选择本身的影响（Section 2）。

## 2 方法/实验范式（LLM如何作为Judge）
- **Judge 模型**（Section 3.1）：GPT-4o-2024-08-06（闭源）+ LLaMA-3.1-70B-Instruct（开源，HuggingFace）。
- **被评模型/响应来源**（Appendix B.2）：Mixtral-8x7B-Instruct-v0.1、Qwen1.5-7B、GPT-3.5-turbo 生成的响应作为 Judge 的输入。
- **评估数据集**（Section 3.1）：
  - [BIGGEN-Bench](../concepts/llm-evaluation-benchmarks.md)（Kim et al., 2024）：9 个任务（指令跟随、工具使用、推理等），每个任务带人工精心编写的细粒度[评估标准](../concepts/evaluation-criteria.md)；**有**人类打分可算相关性。
  - [EvalBiasBench](../concepts/llm-evaluation-benchmarks.md)（Park et al., 2024a）：指令跟随基准，含正确回答与带偏置（biased）回答；[评估标准](../concepts/evaluation-criteria.md)由 GPT-4o-2024-08-06 生成，以引导对偏置响应打低分并提升一致性。**无**人类相关性报告（Table 1 中该基准只给 α 值）。
- **打分方式（prompt 结构）**（Figure 1）：1–5 分制的[单答案评分](../concepts/single-answer-grading.md)（[Single Answer Grading](../concepts/single-answer-grading.md) 式）。Prompt 模板包含：**参考回答（reference answer）** + **[评估标准](../concepts/evaluation-criteria.md)（evaluation criteria）**，其中[评估标准](../concepts/evaluation-criteria.md) = [评估轴](../concepts/evaluation-criteria.md)（evaluation axes，通用评估原则）+ [评分描述](../concepts/evaluation-criteria.md)（score descriptions，每个分数 1–5 分别给出评分细则）。实验变体：Default（完整）、w/o crt（去掉[评估标准](../concepts/evaluation-criteria.md)，以 [MT-Bench](../concepts/llm-evaluation-benchmarks.md) prompt 为底，Figure 3）、w/o ref（去掉[参考答案](../concepts/reference-quality.md)）、w/o ref&crt（两者都去掉）；另做"只保留分数 1 和 5 的描述"的部分删除实验（Figure 2）。
- **[解码策略](../concepts/decoding-strategies.md)**（RQ2 设计，Section 3.2）：确定性 = [greedy](../concepts/decoding-strategies.md)；非确定性 = 采样 5 次（seeds {0,10,20,30,40}，temperature 1.0，repetition penalty 1.03，max seq len 8192，Table 4），再用 Majority（多数票）/ Median（中位数）/ Mean（平均）三种方式聚合。
- **[CoT](../concepts/chain-of-thought.md) 设置**（RQ3 设计）：Direct（直接输出分数，无推理）vs w/ [CoT](../concepts/chain-of-thought.md)（先 [Chain-of-Thought](../concepts/chain-of-thought.md) 推理再输出分数）；RQ3 仅用 GPT-4o。
- **评估指标**（Section 3.1 + Appendix A）：
  - [与人类对齐](../concepts/correlation-coefficient.md)：计算人与 Judge LLM 分数的**[相关系数](../concepts/correlation-coefficient.md)**——论文仅写 "correlation coefficient"，未指明 [Pearson](../concepts/correlation-coefficient.md) 还是 [Spearman](../concepts/correlation-coefficient.md)（论文未明确说明）。
  - 一致性：**[Krippendorff's alpha](../concepts/krippendorff-alpha.md)**（α=1 完全一致，0 随机注释，负值系统性分歧；得分按区间尺度（interval scale）处理，公式见 Appendix A）。
- **其它细节**：抽到 5 个样本分数算 α（Table 1 caption）；若某样本输出非法分数，换 seed 重试直到全部样本输出合法分数（Appendix B.1）。

## 3 效果如何（Results，含具体数字与表/图号）
**RQ1 — 评估设计（Table 1：[Krippendorff](../concepts/krippendorff-alpha.md)'s α（括号内为与人类判断的[相关系数](../concepts/correlation-coefficient.md)），[BIGGEN-Bench](../concepts/llm-evaluation-benchmarks.md)）**
| 方法 | GPT-4o | LLaMA3.1-70B-Instruct |
|---|---|---|
| Default | 0.908 (0.666) | 0.806 (0.641) |
| w/o crt | 0.909 (0.591) | 0.807 (0.555) |
| w/o ref | 0.921 (0.638) | 0.824 (0.581) |
| w/o ref&crt | 0.896 (0.487) | 0.758 (0.346) |
- 去掉[评估标准](../concepts/evaluation-criteria.md)或[参考答案](../concepts/reference-quality.md)都使人类相关性下降：GPT-4o 从 0.666 降到 0.591 / 0.638；LLaMA3.1 从 0.641 降到 0.555 / 0.581（Section 3.2, RQ1 正文）。
- **[评估标准](../concepts/evaluation-criteria.md)比[参考答案](../concepts/reference-quality.md)影响更大**（两个评估器结论一致）；相关性退化在更弱的评估器 LLaMA3.1 上更明显；两者都去掉时相关性降到最低（0.487 / 0.346）。
- **一致性**：[BIGGEN-Bench](../concepts/llm-evaluation-benchmarks.md) 上删除组件基本不影响 α；但 [EvalBiasBench](../concepts/llm-evaluation-benchmarks.md) 上删除[评估标准](../concepts/evaluation-criteria.md)使 α 明显下降（GPT-4o 0.865→0.839；LLaMA3.1 0.768→0.725）——说明"对偏置响应打低分"的明确标准对一致性至关重要（Section 3.2）。
- **Figure 2（部分删除[评分描述](../concepts/evaluation-criteria.md)）**：只给分数 1 和 5 的描述时，与人类判断相关性最高且一致性保持高；与给出全部 1–5 描述差异很小 → 中间分数（2、3、4）的描述作用有限，其必要性应被重新考虑。另有"令人惊讶"的发现：所有设置下评估一致性普遍偏高——即使没有详细[评分描述](../concepts/evaluation-criteria.md)，只要给出通用[评估轴](../concepts/evaluation-criteria.md)，评估仍趋于一致（具体数值在图中，纯文本未提取，论文未明确说明）。

**RQ2 — [解码策略](../concepts/decoding-strategies.md)（Table 2，[BIGGEN-Bench](../concepts/llm-evaluation-benchmarks.md) 上与人类判断的[相关系数](../concepts/correlation-coefficient.md)；列依次为 Default / w/o crt / w/o ref / w/o ref&crt）**
- GPT-4o：[Greedy](../concepts/decoding-strategies.md) 0.635/0.571/0.614/0.466；Majority 0.647/0.583/0.627/0.480；Median 0.648/0.581/0.621/0.481；**Mean 0.666/0.591/0.638/0.487**。
- GPT-4o w/o [CoT](../concepts/chain-of-thought.md)：[Greedy](../concepts/decoding-strategies.md) 0.636/0.507/0.612/0.378；Majority 0.643/0.545/0.627/0.406；Median 0.651/0.546/0.629/0.399；**Mean 0.664/0.570/0.641/0.422**。
- LLaMA3.1：[Greedy](../concepts/decoding-strategies.md) 0.593/0.524/0.551/0.273；Majority 0.625/0.519/0.555/0.297；Median 0.624/0.520/0.558/0.297；**Mean 0.641/0.555/0.581/0.346**。
- 结论（Section 3.2, RQ2）：非确定性的三种聚合方法相关性一致地大于 [greedy](../concepts/decoding-strategies.md)；三种非确定方法中 Mean（平均）最大，且该结论在评估器、评估设计、是否用 [CoT](../concepts/chain-of-thought.md) 上均成立。解释：平均能表达细粒度倾向（如 4 与 5 之间打 4.5），而中位数/多数票会舍入成 4 或 5，未充分利用评估 LLM 的能力。"[greedy](../concepts/decoding-strategies.md) 零方差但相关性低"是典型的权衡结果（与[自一致性](../concepts/self-consistency.md)文献 Wang et al., 2023 一致）。

**RQ3 — [CoT](../concepts/chain-of-thought.md)（Table 3，GPT-4o；[BIGGEN-Bench](../concepts/llm-evaluation-benchmarks.md) 为 α（相关性），[EvalBiasBench](../concepts/llm-evaluation-benchmarks.md) 仅 α）**
- [BIGGEN-Bench](../concepts/llm-evaluation-benchmarks.md)：Default Direct 0.912 (0.664) vs w/ [CoT](../concepts/chain-of-thought.md) 0.908 (0.666)；w/o crt 0.818 (0.570) vs 0.909 (0.591)；w/o ref 0.910 (0.641) vs 0.921 (0.638)；w/o ref&crt 0.833 (0.422) vs 0.896 (0.487)。
- [EvalBiasBench](../concepts/llm-evaluation-benchmarks.md)：Default 0.855 vs 0.865；w/o crt 0.856 vs 0.839；w/o ref 0.647 vs 0.869；w/o ref&crt 0.650 vs 0.811。
- 结论（Section 3.2, RQ3）：在给出[评估标准](../concepts/evaluation-criteria.md)+[参考答案](../concepts/reference-quality.md)的 Default 设置下，w/ [CoT](../concepts/chain-of-thought.md) 与 Direct 的相关性（0.666 vs 0.664）和一致性（0.908 vs 0.912）几乎相同 → **[评分描述](../concepts/evaluation-criteria.md)清晰时显式 [CoT](../concepts/chain-of-thought.md) 收益很小**。

**失败/反向结果的汇总**：weak evaluator（LLaMA3.1）在 w/o ref&crt 下相关性跌到 0.346（Table 1）/ [greedy](../concepts/decoding-strategies.md) 仅 0.273（Table 2）；[greedy](../concepts/decoding-strategies.md) 虽然零方差却牺牲[与人类对齐](../concepts/correlation-coefficient.md)；中间分数描述的作用被证伪（Figure 2）；[CoT](../concepts/chain-of-thought.md) 在信息充分时不带来显著增益（Table 3 Default），且 [EvalBiasBench](../concepts/llm-evaluation-benchmarks.md) 的 w/o ref 下 Direct 仅 0.647 的一致性（远低于 w/ [CoT](../concepts/chain-of-thought.md) 的 0.869）。

## 4 实验对比的 Baseline
- **人类判断（[ground truth](../concepts/ground-truth-and-proxy.md)）**：人与 Judge 分数的[相关系数](../concepts/correlation-coefficient.md)是对齐性的直接参照（[BIGGEN-Bench](../concepts/llm-evaluation-benchmarks.md) 有人类打分；[EvalBiasBench](../concepts/llm-evaluation-benchmarks.md) 未报告人类相关性）。
- **评估设计消融（内部基线）**：Default（完整 prompt，参考回答+[评估标准](../concepts/evaluation-criteria.md)）为基线，对比 w/o crt、w/o ref、w/o ref&crt（Table 1、Table 3）；以及[评分描述](../concepts/evaluation-criteria.md)全给 1–5 vs 只给 1 和 5（Figure 2）。
- **[解码](../concepts/decoding-strategies.md)基线**：[greedy](../concepts/decoding-strategies.md)（确定性、零方差）作为采样[解码](../concepts/decoding-strategies.md)（Majority/Median/Mean）的对照（Table 2）。
- **[CoT](../concepts/chain-of-thought.md) 基线**：Direct（直接打分、不输出推理）作为 w/ [CoT](../concepts/chain-of-thought.md) 的对照（Table 3）。
- **Judge 模型互为对照**：闭源 GPT-4o vs 开源 LLaMA-3.1-70B-Instruct。
- **传统自动指标**：[BLEU](../concepts/traditional-auto-metrics.md)、[ROUGE](../concepts/traditional-auto-metrics.md)、CIDEr（词法）、[BERTScore](../concepts/traditional-auto-metrics.md)、COMET（语义）仅在 Related Work（Section 2）中作为"难以处理多样合法回答任务"的既有方法被提及，**本实验未与它们做数值对比**（论文未明确说明）。
- 注：论文没有引入其他第三方 Judge 模型/专门的 Judge 训练模型作对比基线。

## 5 Insights（结论/局限/启示）
**论文作者的主张：**
1. **评估设计是关键**：参考回答与[评分描述](../concepts/evaluation-criteria.md)缺一不可——去掉任一组件的伤害在弱评估器上更明显（Section 3.2 RQ1、Table 1）；且**中间分数（2/3/4）的[评分描述](../concepts/evaluation-criteria.md)必要性应被重新考虑**（Figure 2）。
2. **[解码策略](../concepts/decoding-strategies.md)**：采样 + 平均 > [greedy](../concepts/decoding-strategies.md)；[greedy](../concepts/decoding-strategies.md) 保证零方差但相关性更低，采样能更好捕捉人类偏好的细微差别，因此建议用"多采样 + 分数平均"（Section 3.2 RQ2、Table 2）。
3. **[CoT](../concepts/chain-of-thought.md) 收益递减**：[评估标准](../concepts/evaluation-criteria.md)清晰时 [CoT](../concepts/chain-of-thought.md) 几乎无增益；从成本与性能综合看，**"无 [CoT](../concepts/chain-of-thought.md) 打分 + 分数平均"** 以低计算成本获得强人类对齐（Section 3.2 RQ3、Table 3、Conclusion）。
4. 对偏置评估（[EvalBiasBench](../concepts/llm-evaluation-benchmarks.md)）：必须为"偏置响应"明确写出打分标准，否则评分可能依赖随机因素而失去一致性（Section 3.2 RQ1）。
5. 意外发现：即使缺少详细[评分描述](../concepts/evaluation-criteria.md)，只要提供通用[评估轴](../concepts/evaluation-criteria.md)，评估一致性依然普遍较高（Section 3.2）。

**从数据中可以看到的补充观察（正文未强调）：**
- 在信息不足的变体（w/o ref&crt、[EvalBiasBench](../concepts/llm-evaluation-benchmarks.md) 的 w/o ref）中，[CoT](../concepts/chain-of-thought.md) 的一致性增益很大（如 [EvalBiasBench](../concepts/llm-evaluation-benchmarks.md) α 0.647→0.869；BIGGEN 0.422→0.487），说明 [CoT](../concepts/chain-of-thought.md) 的价值随 prompt 信息完整度变化，而非一概"无用"（Table 3）。
- 所有设置下与人类判断的相关性最高仅约 0.67（Table 1/Table 2 的 GPT-4o Mean），整体处于中等偏高水平，仍与人类级评估有距离。
- Table 1 括号相关性（0.666 等）与 Table 2 的 Mean 行数值一致，说明 Table 1 的相关性即为五个样本分数平均后的相关。

**局限（Section 5）：**
- 仅用 2 个评估器（GPT-4o 闭源、LLaMA-3.1-70B 开源），结论能否推广到其他 LLM 未验证。
- 两个基准的[评估标准](../concepts/evaluation-criteria.md)来源不同（[BIGGEN-Bench](../concepts/llm-evaluation-benchmarks.md) 人工编写 vs [EvalBiasBench](../concepts/llm-evaluation-benchmarks.md) LLM 生成），更多样的标准生成方式有待研究。
- 所有数据均为英文，其他语言待验证。
