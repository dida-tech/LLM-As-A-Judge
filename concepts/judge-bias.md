# Judge 偏差（Judge Bias，总论）

## 这是什么（定义）
judge 的判断被**与答案真实质量无关的因素**系统性地左右。偏差 = judge 的分数受到"多余信号"（位置、长度、格式、来源、自身偏好…）稳定的影响。数学上（[2410.13341] §2）：bias = E[judge 分数] − 真实分数。

## 通俗直觉
阅卷老师看见"字写得漂亮"就给高分、看见"第一份试卷"就格外宽容——这些和内容质量无关，但判断被稳定地带偏了。

| 偏差 | 一句话 | 来自 |

| [位置偏差](position-bias.md) | 排在前/后面的答案更受青睐 | 普遍 |
| [冗长偏差](length-bias.md) | 越长越像"更认真" | 普遍 |
| [自偏好偏差](self-preference-bias.md) | 偏爱自己（或同类模型）的输出 | 普遍 |
| [权威偏差](authority-bias.md) | 有引用/权威外表的答案更受信任 | [2402.10669] |
| [美学偏差](beauty-bias.md) | emoji/排版等"好看"干扰注意力 | [2402.10669] |
| [性别偏差](gender-bias.md) | 对性别相关内容的不公判断 | [2402.10669] |

## 数值/结果怎么读
- 本调研的量化方式：干预实验测 [ASR](attack-success-rate.md)（偏好被扰动带偏的比例）；理想≈0，>0.3 已经很严重。
- [2402.10669] Table 1 显示：假引用（权威偏差）下绝大多数 judge 的 ASR 不低于随机瞎选（0.37+），最高 0.89；富格式（美学）下人类高达 0.47。
- 位置偏差：GPT-4o 的"偏第一份"比例 0.186，GPT-3.5-turbo 高达 0.840（[2402.10669] Table 5）。

## 为什么重要（隐藏含义）
- 偏差意味着**分数里混入了与质量无关的成分**：排行榜差距、训练信号、评审意见都可能被污染。
- 关键论点是：**人类 judge 也有偏差**（[2402.10669] Table 1）——"人不是天然的金标准"，很多偏差是双方共有的。
- 工程对策：交换顺序重评（位置）、长度控制提示（冗长）、提供正确参考并核验（权威/自偏好）、报告多扰动下的鲁棒性。
