# 参考质量（Reference Quality）

## 这是什么（定义）
评测中所用**参考答案（gold/reference）本身的对错与好坏**。参考可以是：人类专家写的（Human）、模型生成的（Self）、人工改错过的（Wrong）、从别处随机抽的（Random）。参考质量 = 它是否**正确、无歧义、且足以覆盖"正确回答"的空间**。

## 通俗直觉
判卷要有标准答案，但标准答案自己先得是对的。用带错的参考答案判卷，等于拿着错答案去挑对答案的毛病。

## 数值/结果怎么读（本方向最重要的隐藏变量）
- [2503.05061] Table 3 的对照实验：**参考的"正确性"远比"是否人手写的"重要**——人类写的与"人类核验过的模型生成参考"差别不大，与 Wrong 参考差别巨大。
- **错误参考（Wrong）比没有参考更糟**：它会诱导 judge 把正确回答判错（FPR↓/FNR↑，§6, Figure 4）。
- 现实冲击：MT-Bench 官方参考 **37.5%（15/40）错误或不一致**（[2503.05061] §3.2）——主流基准的参考也带雷。
- 关联：Self 参考（用 judge 自己的回答）会放大[自偏好偏差](self-preference-bias.md)（§6）。

## 为什么重要（隐藏含义）
- 参考质量是"评测管线的最薄弱环节"：judge 的全部智慧都从参考里取，参考错了，一切白搭。
- 实践处方（[2503.05061] §7）：**至少核验参考**——不必每题手写，核验模型生成的参考即可，这是可靠性×可扩展性的折中。
- 一个连锁推论：排行榜、微调数据、RLHF 管线里"reference"的质量应该和模型质量一起被审计——目前很少有人审计。
