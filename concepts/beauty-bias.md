# 美学偏差（Beauty Bias，富格式干扰）

## 这是什么（定义）
judge 因为答案在**视觉/格式上"好看"**（emoji、Markdown 标题、粗体、表格、花哨排版）而给更高分，即使内容没变甚至更差。测试用的扰动叫 **rich content（富内容）**：给普通答案加上 emoji/排版。

## 通俗直觉
把论文排版得漂亮一点，导师就多给两分——AI 阅卷官对此同样没有免疫力。

## 数值/结果怎么读
- [2402.10669] Table 1（ASR，越低越好）：Claude-3 **0.04**、GPT-4-Turbo 0.05、GPT-4o 0.07、Ernie 0.09（这些模型对排版免疫）；但**人类 0.47**、LLaMA2-70B 0.46、Claude-2 0.68——人对"好看"的抵抗力反而更差。
- 说明"富格式"这类信号对强 LLM 的干扰有限，但对**人和弱模型**很有效（[2402.10669] §5.2.2）。

## 为什么重要（隐藏含义）
- 反直觉的事实：**人类 judge 在"能不能被排版骗到"上并不比顶级 LLM 强**——再次印证"人类不是天然金标准"（[2402.10669]）。
- LLM 对此免疫的可能原因：emoji/markdown 在正常训练语料里少见，充当"注意力干扰物"时大模型能忽略；而人类视觉通道天然被排版吸引（作者假说，[2402.10669] F.2）。
- 对产品影响：若评测链路里有格式化环节（如带渲染的 UI 众包评测），格式差异会悄悄污染分数。
