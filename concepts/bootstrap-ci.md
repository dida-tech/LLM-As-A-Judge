# Bootstrap 置信区间（Bootstrap Confidence Interval）

## 这是什么（定义）
一种**不假设分布**的重抽样统计方法：从观测样本里反复有放回地抽"与原始数据一样大"的样本（通常 1000 次以上），每次算出统计量（如 κ），把得到的分布里 2.5%–97.5% 的分位点作为 95% 置信区间。它回答："这个一致性数字，如果重做一遍实验，大概会落在哪个范围？"

## 通俗直觉
没有"标准答案的公式"，就靠反复抽签来感觉统计量有多稳：把 1200 个样本抽 1000 次，看 κ 每次大概在什么范围波动。范围越窄 = 结论越稳。

## 数值/结果怎么读
- 区间不含 0 → 效应"统计显著"；两个区间重叠大 → 差异可能只是噪声。
- [2503.05061] 的用法（Table 11）：如 single-BFF 上"无参考、答案对/错两层的 κ 差" = +0.249，95% CI [0.19, 0.31]——区间下限远高于 0，结论非常稳；而 Human 参考下差距 [CI 上限 +0.05]——提升后差距"不再显著"，即参考把洞补上了。
- 尤其适合小样本 + 复杂指标（κ、相关）的场景，比大样本正态近似更诚实。

## 为什么重要（隐藏含义）
- 评测结论经常只给一个点估计（"κ=0.86"），不带不确定性；Bootstrap 让"0.86 vs 0.16"这样的大差距有统计支撑，也防止把"0.60 vs 0.62"当回事。
- 在 [2503.05061] 里它支撑了核心论断"答对/答错层的差异是真实存在的，不是抽样噪声"。
