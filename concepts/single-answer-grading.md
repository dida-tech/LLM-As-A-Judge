# 单答案评分（Single Answer Grading）

## 这是什么（定义）
最直接的打分范式：把"题目 + 一个候选回答"交给 judge，让它给出分数（常见 1–5 或 1–10 分制），可附加**参考答案**和**评分标准**来约束打分的依据。

## 通俗直觉
"这份卷子打几分？"——judge 只有一份答案要评，没有另一份对照。它自己心里要有一个"好答案长什么样"的标尺。

## 数值/结果怎么读
- 分制与解读：1–5 分制中给了每档的分数描述时最可靠；只给最高/最低档描述（1 和 5）可能就够用了（[2506.13639] Figure 2）。
- 参考+标准齐备时，GPT-4o 与人类相关性可达 **0.666**；两者都去掉则跌到 **0.487**（[2506.13639] Table 1）——同一篇论文里两个数字的差距就是"设计"的威力。
- 单答案评分在 [2406.13439] 中是检出率最弱的范式之一（>50% 质量下降检不出，参考 [未检出率](undetected-rate.md)）。

## 为什么重要（隐藏含义）
- 没有参考对象时，judge 的"内部标尺"很容易漂移：不知道什么算 4 分什么算 5 分，中间档位的分数描述作用有限（[2506.13639] Figure 2）。
- 它对评估标准最敏感：**标准比参考更重要**，弱 judge（如 LLaMA-3.1-70B）退步更明显（[2506.13639] Table 1）。
- 现实含义：排行榜上"GPT-4 得分 8.1 vs Claude 8.0"这类分数，取决于 judge 的 prompt 设计，差的配置可能让差距失真。
