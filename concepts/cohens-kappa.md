# Cohen's Kappa（κ）

## 这是什么（定义）
衡量**两个评判者**（如 judge 与人类）在**分类判断**上的一致程度，且**扣除掉"碰巧蒙对"的成分**。公式：κ = (观察一致率 − 偶然一致率) / (1 − 偶然一致率)。取值 −1 到 1。

## 通俗直觉
两个人独立判"对/错"，看他们有多少比例结论一样；但两人都可能习惯性说"对"，这部分的"一致"不算数，要剔除"瞎猜也能猜中的部分"。比如两个人都 90% 说"对"，偶然一致率很高，κ 就不会是 0.9。

## 数值/结果怎么读（常用对照标尺）
| κ 范围 | 解释 |
|---|---|
| < 0 | 比随机还差 |
| 0.0–0.2 | 几乎无一致（≈随机） |
| 0.21–0.40 | 轻度一致 |
| 0.41–0.60 | 中等一致 |
| 0.61–0.80 | 较强一致 |
| 0.81–1.00 | 很强一致 |

- 本调研中的关键读数：[2503.05061] 里 judge"会答的题"上 κ 可达 **0.747–0.880**（很强），但"不会答的题"且无参考时 κ 只有 **0.085–0.256**（≈随机）——**同一个 judge，两道题的 κ 可以从"很强"掉到"瞎猜"**。

## 为什么重要（隐藏含义）
- κ 把"能力"和"侥幸"分开，比裸的一致率更诚实。二分类任务（对/错）特别适合用它，因为它对"一边倒"的分布敏感。
- 当任务难度不均时，总体 κ 会掩盖局部问题——这是 [2503.05061] 坚持按题目分层报告 κ 的原因（§6, Table 11）。
- 区别于 [相关](correlation-coefficient.md)：相关看"趋势一致"，κ 看"结论相同"，两者互补。
