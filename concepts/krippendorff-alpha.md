# Krippendorff's Alpha（α）

## 这是什么（定义）
衡量**多个评判者（或同一评判者多次）之间评分一致性**的通用指标，取值 −1 到 1。1=完全一致，0=和随机标注一样，负值=系统性分歧。它比 [Cohen's κ](cohens-kappa.md) 更通用：可以支持多个评分者、多种量纲（分类/序数/区间/比率）、允许缺失数据。

## 通俗直觉
同一个 judge 把同一份答卷判两遍（或换种子重判），两次给的分一样稳定吗？α 高的意思是："无论随机因素怎么变，打分结果都差不多"。

## 数值/结果怎么读
- 0.8 以上通常视为可接受的一致水平，0.9 以上很好。
- 本调研读数：GPT-4o 在标准+参考齐备时 α=**0.908**；全部去掉设计要素时 α 仍 0.896（[2506.13639] Table 1）——**注意：α 只反映"稳定"，不代表"准确"**：judge 可以稳定地错（[2509.20293] 的"高置信噪声"就是这个道理）。
- 有趣现象：EvalBiasBench 上去掉"惩罚有偏回答"的标准，α 从 0.865 跌到 0.839（[2506.13639] Table 1）——没有明确标准，打分就开始随机。

## 为什么重要（隐藏含义）
- **"稳定"和"正确"是两回事**。这是本方向最容易混淆的一对概念：α 高只能说明重复性好；judge 可能与人类系统性不一致（相关 [相关系数](correlation-coefficient.md) 低）却自我一致（α 高）。
- 采样聚合（多次打分取平均）能同时提升稳定性和对齐——采样+平均在相关上超过 greedy 解码（[2506.13639] Table 2；[解码策略](decoding-strategies.md)）。
