# 位置偏差（Position Bias）

## 这是什么（定义）
在成对比较中，judge 倾向选择**出现在前面（或后面）**的答案，与答案本身质量无关。量化方式：统计选"第一个答案"的比例减去选"第二个答案"的比例（Diff = First − Second），接近 0 最理想。

## 通俗直觉
选择题总是选 A 的同学——有些 judge "天生"偏爱第一项或第二项，超参数和 prompt 都改不掉。

## 数值/结果怎么读
- |Diff|<0.1 基本无偏；0.1–0.3 中等；>0.3 严重影响可信度。
- [2402.10669] Table 5：人类 0.006（几乎无偏）、GPT-4 0.056（轻微）、GPT-4o 0.186、LLaMA2-70B 0.215、GPT-3.5-turbo **0.840**（几乎只看位置）、Mixtral 0.327、Spark −0.417（反过来，偏爱第二个）。
- 位偏严重的 judge（GPT-3.5-turbo、Mixtral、Spark）被 [2402.10669] **直接排除出主实验**；另一极端是"永远平局"（Qwen Tie 率 0.975、Gemini-Pro 0.862），也等于无信息。

## 为什么重要（隐藏含义）
- 成对比较排行榜（如 Chatbot Arena）如果不做位置校正，结果会被 judge 的习惯性偏好染色。
- 标准处理：**同一个比较对，正反顺序各评一次，结论一致才算数**（[2503.05061] §4.2 即如此，参照 Zheng 2023）。
- 教训：**"过了位置筛选"的 judge 仍有中等位偏**（Claude-3 0.104、Ernie 0.156），主结论并未彻底剥离位置因素（[2402.10669] Appendix F.1 的观察）。
