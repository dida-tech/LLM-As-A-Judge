# 参考引导评测（Reference-Guided Evaluation）与参考类型

## 这是什么（定义）
在打分时**额外提供一份参考答案（reference/gold answer）**，让 judge 对照它来评估候选回答。参考可以来自人类专家书写，也可以来自模型生成。参考的"好坏"本身是决定 judge 表现的关键变量。

## 通俗直觉
阅卷时把"标准答案"放在旁边对照——有标准答案的判卷比分岔判卷可靠得多，但**如果标准答案本身是错的，反而会误导阅卷**。

## 数值/结果怎么读
- [2506.13639] Table 1：提供参考 vs 不提供，GPT-4o 与人类相关 0.638 vs 0.666（去掉标准影响更大）；两者都去掉跌到 0.487。
- [2406.13439] Table 3：参考引导范式下漏检率从 0.57–0.71（单答案）降到 0.04–0.49，是三种范式中最好的；但指令遵循类仍漏近一半（0.49）。
- 参考类型实验（[2503.05061] §4.3）：**None（无）/ Self（judge 自己的回答）/ Human（专家正确参考）/ Wrong（人为写错的参考）/ Random（无关参考）**。结果：正确参考提升一致性，**错误参考比没有参考更糟**（把正确的回答判成错）。

## 为什么重要（隐藏含义）
- 参考的质量 > 参考的来源：人类写的参考和"经人工核验正确"的模型参考差别不大，关键是**正确**（[2503.05061] §6, Table 3）。
- 反面警示：MT-Bench 官方参考答案中有 **37.5%（15/40）是错误的或不一致的**——连主流基准的参考都可能带错（[2503.05061] §3.2）。
- 自偏好偏差：用 judge"自己的回答"当参考（Self）会放大偏差（[2503.05061] §6；[自偏好偏差](self-preference-bias.md)）。
- 实践处方：**至少核验参考答案**，这是可靠性×可扩展性的折中点（[2503.05061] §7）。
